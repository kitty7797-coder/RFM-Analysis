# RFM-Analysis
-  利用RFM三個指標製作成圖表，做分析洞察
## 什麼是RFM呢?
- R,Recency（近因性）,顧客最近一次消費時間距離今天有多久,時間越近，分數越高。代表顧客對品牌的記憶度與活躍度。
- F,Frequency（頻率）,顧客在指定期間內的消費總次數,次數越多，分數越高。代表顧客對品牌的黏著度與忠誠度。
- M,Monetary（金額）,顧客在指定期間內的消費總金額,金額越高，分數越高。代表顧客對企業的商業價值與貢獻度。

## 這些可以幹嘛呢?
- 我們會將他們製作成客戶分群統計與策略表
- 運用方式：有了 K-means 分好的 Group 標籤後，再使用 groupby('Group') 對全體客戶進行加總與平均值計算。
- 產生結果：產出各分群的人數占比、總貢獻金額與平均客單價，作為向上層匯報與制定商業策略的依據。
